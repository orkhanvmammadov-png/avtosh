Interaction notes
Gallery: ‹ › arrows + thumbnail click select the image (selected thumb: 2px green outline); "+n" tile jumps into sequence. Keyboard: ←/→ navigate, thumbs focusable. Full-screen view is a pure UX layer over the same images — no new backend contract. Fewer images: thumb row shows only real images; single image hides the row; ratios fixed, zero layout shift.
Mobile gallery: swipe + counter + segment progress; no thumb rail, no arrows; tap opens full-screen swipe view.
Contact: "Nömrəni göstər" → existing reveal endpoint → button becomes the phone number (pressed #0F6440); SOLD/EXPIRED never render the CTA.
Favorite: existing tri-state contract; selected = filled red heart on tinted ground; outline variant on navy. Never competes with the CTA.
Description: clamp at 6 lines → "Daha çox ▾" expands in place, "Daha az ▴" collapses; short text never clamps.
Sticky bar (390): phone CTA + favorite, 48px targets, safe-area padded, content gets 72px bottom offset; hidden for SOLD/EXPIRED.
Report: "Şikayət et" quiet red text in the seller row — existing flow, never competing with contact.
Breakpoint summary
1440: stage = gallery + 400px panel, gutter 40; hero 16:10; lower page 2-col.
1024: panel 340, gutter 32; same architecture, spec tiles 3-up.

Accessibility: AA contrast on navy (#A7ADB8+ text, white values); 2px green focus ring on all controls; badges carry text, never color alone.
