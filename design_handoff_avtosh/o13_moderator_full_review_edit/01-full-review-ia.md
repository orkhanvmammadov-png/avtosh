# Full review — information architecture
Default detail mode: READ/REVIEW. Structure top-to-bottom: header (type tag YENİ ELAN / ELAN REDAKTƏSİ + subject + claim state) → "Dəyişikliklərin müqayisəsi" (changed-first; present when adjustment or seller edit exists) → "Elanın bütün məlumatları" (complete structured sections) → decision footer. Explicit "Redaktə et" button enters edit mode — default screen is never a giant editable form.
## Complete coverage (no seller marketplace field omitted)
Nəqliyyat vasitəsi: category, brand, model, year. Detallar: body, engine, fuel, transmission, drive, motorcycle-specific attributes (category-aware), color. Satış: price, mileage, city, credit, barter, condition claims (Vuruğu yoxdur / Rənglənməyib). Təchizat: FULL O.11-grouped selected equipment (never hidden, never diff-only for LISTING_EDIT — full proposed set inspectable). Şəkillər: complete submitted/proposed gallery, order, primary (Əsas badge). Təsvir: full text. Əlaqə: seller name + full authorized contact value (unmasked; no unrelated account data).
Section chrome: .modSec cards — gray group header (10.5/600), label/value rows, hairline separators. Missing optional values → row hidden.
