# Progress model
Authoritative: **Mərhələ X / 6** — journey position only. It never claims data completeness, database state, or percentage.
- Header (all widths): navy bar center text "Mərhələ X / 6" (390: replaces the O.9 "n/7" slot).
- X = furthest reached stage; reopening an earlier section via Dəyiş does NOT decrement X.
- DEPRECATED: the O.9 "n / 7 tamam" completion model — remove entirely; do not display "tamam" counts anywhere.
- No percentages, no fake completion bars.
Distinct concepts (never conflated): journey position (Mərhələ X/6) · visited (stage acknowledged) · valid (required data passes) · needs attention (visited + invalid required data).
