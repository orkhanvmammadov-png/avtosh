Design notes
Collapsed → expanded: same 1C inline behavior as Home — panel opens under the compact row inside the card, grid pushes down (240ms ease); collapse keeps values, count chip shows "n filtr".
Apply: Axtar refreshes results, panel auto-collapses, chips re-render from the applied query (URL-as-state preserved). Chip ✕ removes one criterion and refreshes; Təmizlə clears all.
Sort: separate 36px control in the chips/toolbar row, right-aligned; existing sort options only; never inside Advanced Search.
Boost integration: one deduplicated grid; eligible boosted listings (matching category + all active filters) fill the first-view slots — 4 @1440, 3 @1024/768, 2 @390 — via existing rotation; organic results continue in the same grid with zero visual separation beyond the badge.
Load more: "Daha çox göstər" continues organic results on the existing cursor; boost slots are not re-inserted on continuation. No numbered pagination.
Responsive deltas: grid 4/3/3/1-up @1440/1024/768/390; expanded panel reuses O.2 recipes verbatim (spine 340 → spine 300 → price band → single column); chips wrap, never scroll horizontally; mobile Sort sits beside the Ətraflı toggle in a pinnable toolbar row.
Unchanged: listing card anatomy, filter order 1–10 + city-as-general, all search/Boost/rotation/pagination contracts. No result counts anywhere new.
